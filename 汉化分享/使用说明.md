# AI-Toolkit Web UI 汉化分享包

## 包含内容
- `ai-toolkit-l10n-v0.13.4.patch` —— git 补丁（推荐，用于 git 克隆的仓库）
- `ai-toolkit-l10n-overlay-v0.13.4.zip` —— 直接覆盖版（适合不想用 git 的人）
- 本说明文件

## 适用版本
- 基于官方仓库 **ostris/ai-toolkit v0.13.4**（commit 9d6a9a0）
  官方地址：https://github.com/ostris/ai-toolkit
- 若接收者仓库版本不同，补丁可能部分应用失败、覆盖版文件也可能不完全对应，请先确认版本一致。

## 汉化内容
- 采用**双语格式**：`中文 (English)`，完整保留英文原文。
- 专有名词与官方术语保留英文（LoRA、FLUX、GPU、Checkpoint、Caption 等）。
- 共 **51 个文件**，全部位于 `ui/src/` 目录下（页面、组件、帮助文档、配置项等）。

---

## 方式一：git 补丁（推荐）
接收者需要已克隆 ai-toolkit（版本一致）：

    git clone https://github.com/ostris/ai-toolkit.git
    cd ai-toolkit
    git apply ai-toolkit-l10n-v0.13.4.patch

应用成功后无需手动处理，改动会直接进入工作区。

## 方式二：直接覆盖（适合非 git 用户）
解压 `ai-toolkit-l10n-overlay-v0.13.4.zip`，把其中的 `ui/` 文件夹合并覆盖到 ai-toolkit 仓库根目录（保留目录结构）。

---

## 应用后如何生效
汉化改的是前端源码，必须重新构建才能看到效果：

    cd ui
    npm install      # 首次需要安装依赖
    npm run build    # 重新构建前端
    cd ..
    python -m manager launch    # 启动 UI，浏览器访问 http://localhost:8675

（Windows 下若 python 不在 PATH，用 `python -m manager launch` 前先激活 venv，或使用仓库根目录的 `.venv\Scripts\python.exe -m manager launch`。）

## 注意事项
- 汉化基于 v0.13.4 的源码上下文；上游更新后这些文件可能被覆盖或产生冲突，更新前请备份汉化（可先用 `git stash` 或复制文件）。
- 补丁与覆盖版内容一致，任选一种方式即可，不要重复使用。
- 若同时需要"一键关闭 UI"和"一键更新"工具，请一并拷贝同目录下的 stop_ui.bat / stop_ui.ps1 / update_ai_toolkit.bat / update_ai_toolkit.ps1。
